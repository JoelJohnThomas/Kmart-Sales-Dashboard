# Sales Dashboard

## 📊 Project Overview

The objective of this project was to transform raw sales data into an interactive and easy-to-understand dashboard that provides meaningful insights into business performance.

The dashboard was designed to help identify **sales trends, high-performing locations, customer purchasing patterns, and potential opportunities for business growth**.

## 🎯 Objectives

* Analyse overall sales performance and trends
* Identify high-performing states and locations
* Understand customer purchasing behaviour
* Compare sales across different product categories
* Analyse different sales types
* Provide an interactive dashboard for business users to explore the data

## 🔍 Dashboard Features

The dashboard includes interactive filters that allow users to drill down into specific areas of the business:

* **Financial Year** – Analyse sales performance across different financial years
* **State** – Compare sales performance across different states
* **Category** – Explore sales across product categories
* **Sales Type** – Analyse different types of sales and purchasing behaviour

These filters allow users to dynamically explore the data and identify patterns that may not be immediately visible from the raw dataset.

## 📈 Key Insights

The dashboard can be used to identify:

* Sales trends over time
* Top-performing states and locations
* Popular product categories
* Differences in customer purchasing patterns
* Changes in sales performance across financial years
* Potential areas for business growth and improvement

## 🛠️ Tools & Technologies

* **Data Analysis:** Excel / Pivot Table
* **Data Visualisation:** Excel Dashboard / Pivot Charts
* **Data Transformation:** Excel
* **Dataset:** Synthetic Kmart Sales transaction data


## 💡 Project Outcome

This project demonstrates how raw transactional sales data can be transformed into a **business-focused analytical dashboard**. By combining data transformation, analysis, interactive filtering, and visualisation, the dashboard makes it easier for users to understand sales performance and make data-driven business decisions.
